## Теоретическое обоснование

### 1. Что такое анализ сложности алгоритмов?

Анализ сложности — это математический способ оценки эффективности алгоритма в зависимости от размера входных данных.

Различают два вида сложности:

1. **Временная сложность (Time Complexity)** — сколько времени выполняется алгоритм.
2. **Пространственная сложность (Space Complexity)** — сколько памяти использует алгоритм.

### 2. О-нотация (Big O)

О-нотация — это математическая запись, описывающая асимптотическое поведение функции при стремлении аргумента к бесконечности.

**Формальное определение:**

Говорят, что `f(n) = O(g(n))`, если существуют положительные константы `c` и `n₀` такие, что `0 ≤ f(n) ≤ c × g(n)` для всех `n ≥ n₀`.

**Простым языком:** О-нотация показывает, как быстро растёт время работы алгоритма при увеличении входных данных, отбрасывая константы и младшие члены.

| Исходная формула | Упрощение | Сложность |
|---|---|---|
| 5n + 3 | n | O(n) |
| 2n² + 100n + 1000 | n² | O(n²) |
| 3n log n + 4n | n log n | O(n log n) |
| 1000 | 1 | O(1) |

### 3. Основные классы сложности

| Сложность | Название | Описание | Пример |
|---|---|---|---|
| O(1) | Константная | Время не зависит от размера данных | Доступ по индексу в массиве |
| O(log n) | Логарифмическая | Растёт медленно, при удвоении данных время растёт на константу | Бинарный поиск |
| O(n) | Линейная | Время растёт пропорционально размеру данных | Линейный поиск, сумма элементов |
| O(n log n) | Линейно-логарифмическая | Эффективные сортировки | Быстрая сортировка, слиянием |
| O(n²) | Квадратичная | Время растёт квадратично | Пузырьковая сортировка |
| O(2ⁿ) | Экспоненциальная | Время удваивается при добавлении одного элемента | Рекурсивное вычисление Фибоначчи |
| O(n!) | Факториальная | Самый медленный рост | Генерация всех перестановок |

### 5. Определение сложности по коду

```cpp
// O(1) — константная
int getFirst(int arr[], int n) {
    return arr[0];
}

// O(n) — линейная
int sum(int arr[], int n) {
    int total = 0;
    for (int i = 0; i < n; i++) {
        total += arr[i];
    }
    return total;
}

// O(n²) — квадратичная
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                std::swap(arr[j], arr[j + 1]);
            }
        }
    }
}

// O(log n) — логарифмическая
int binarySearch(int arr[], int n, int x) {
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == x) return mid;
        if (arr[mid] < x) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

## Выполнение практической части

### Реализованный класс

**`StaticVector<T, N>`** — статический вектор фиксированной ёмкости. Хранит массив `T data[N]` на стеке (без динамической памяти).

### Операции и их сложность

| Операция | Сложность | Обоснование |
|---|---|---|
| `StaticVector()` | O(1) | Инициализация `sz = 0` |
| `~StaticVector()` | O(1) | Нет динамической памяти |
| `push_back(value)` | O(1) | Проверка + запись в массив |
| `pop_back()` | O(1) | Проверка + уменьшение `sz` |
| `operator[](index)` | O(1) | Прямой доступ по индексу |
| `size()` | O(1) | Возврат поля |
| `empty() / full()` | O(1) | Сравнение |
| `print()` | O(n) | Проход по всем элементам |

**Ключевое отличие от `std::vector`:** отсутствие реаллокации — все операции, кроме `print()`, константные.

### Код программы

```cpp
#include <iostream>
#include <stdexcept>

using namespace std;

// ============================================================
// ШАБЛОННЫЙ КЛАСС Set<T> (Множество на основе BST)
// ============================================================
template <typename T>
class Set {
private:
    // Структура узла дерева
    struct Node {
        T data;
        Node* left;
        Node* right;
        Node(const T& value) : data(value), left(nullptr), right(nullptr) {}
    };

    Node* root; // Корень дерева
    size_t count; // Количество уникальных элементов

    // Вспомогательная функция для рекурсивного удаления дерева
    void clear(Node* node) {
        if (node != nullptr) {
            clear(node->left);
            clear(node->right);
            delete node;
        }
    }

    // Вспомогательная функция для вставки
    Node* insert(Node* node, const T& value, bool& inserted) {
        if (node == nullptr) {
            inserted = true; // Элемент добавлен
            count++;
            return new Node(value);
        }
        if (value < node->data) {
            node->left = insert(node->left, value, inserted);
        }
        else if (value > node->data) {
            node->right = insert(node->right, value, inserted);
        }
        // Если value == node->data, ничего не делаем (дубликаты запрещены)
        return node;
    }

    // Вспомогательная функция для поиска
    bool contains(Node* node, const T& value) const {
        if (node == nullptr) return false;
        if (value == node->data) return true;
        if (value < node->data) return contains(node->left, value);
        return contains(node->right, value);
    }

    // Вспомогательная функция для удаления узла
    Node* remove(Node* node, const T& value, bool& removed) {
        if (node == nullptr) return nullptr;

        if (value < node->data) {
            node->left = remove(node->left, value, removed);
        }
        else if (value > node->data) {
            node->right = remove(node->right, value, removed);
        }
        else {
            // Нашли узел для удаления
            removed = true;
            count--;

            // Случай 1: Нет детей или один ребенок
            if (node->left == nullptr) {
                Node* temp = node->right;
                delete node;
                return temp;
            }
            else if (node->right == nullptr) {
                Node* temp = node->left;
                delete node;
                return temp;
            }

            // Случай 2: Два ребенка. Ищем минимальный в правом поддереве
            Node* temp = node->right;
            while (temp->left != nullptr) temp = temp->left;

            node->data = temp->data; // Копируем значение
            node->right = remove(node->right, temp->data, removed); // Удаляем дубликат
            count++; // Возвращаем счетчик, так как remove внутри уменьшит его еще раз
        }
        return node;
    }

    // Вспомогательная функция для вывода
    void print(Node* node) const {
        if (node != nullptr) {
            print(node->left);
            cout << node->data << " ";
            print(node->right);
        }
    }

public:
    // Конструктор — O(1)
    Set() : root(nullptr), count(0) {}

    // Деструктор — O(n)
    ~Set() {
        clear(root);
    }

    // insert (вставка) — O(log n) в среднем, O(n) в худшем
    void insert(const T& value) {
        bool inserted = false;
        root = insert(root, value, inserted);
    }

    // contains (проверка наличия) — O(log n) в среднем
    bool contains(const T& value) const {
        return contains(root, value);
    }

    // remove (удаление) — O(log n) в среднем
    void remove(const T& value) {
        bool removed = false;
        root = remove(root, value, removed);
    }

    // size (размер) — O(1)
    size_t size() const {
        return count;
    }

    // Вывод (для демонстрации) — O(n)
    void print() const {
        cout << "[ ";
        print(root);
        cout << "]" << endl;
    }
};

// ============================================================
// MAIN
// ============================================================
int main() {
    setlocale(LC_ALL, "ru");

    Set<int> mySet;

    cout << "Добавляем элементы: 50, 30, 70, 20, 40, 60, 80" << endl;
    mySet.insert(50);
    mySet.insert(30);
    mySet.insert(70);
    mySet.insert(20);
    mySet.insert(40);
    mySet.insert(60);
    mySet.insert(80);

    cout << "Содержимое множества (отсортировано благодаря BST): ";
    mySet.print();
    cout << "Размер: " << mySet.size() << "\n\n";

    cout << "Проверка contains(40): " << (mySet.contains(40) ? "true" : "false") << endl;
    cout << "Проверка contains(90): " << (mySet.contains(90) ? "true" : "false") << "\n\n";

    cout << "Удаляем элемент 30..." << endl;
    mySet.remove(30);
    cout << "Содержимое после удаления: ";
    mySet.print();
    cout << "Размер: " << mySet.size() << "\n\n";

    cout << "Пытаемся добавить дубликат (50)..." << endl;
    mySet.insert(50);
    cout << "Размер остался прежним: " << mySet.size() << endl;

    cout << "\nНажмите Enter для выхода...";
    cin.get();
    return 0;
}
```

## Анализ сложности

Все операции реализованы на основе бинарного дерева поиска (BST). В таблице указана сложность в зависимости от структуры дерева.

| Операция | Сложность (средняя) | Сложность (худшая) | Обоснование |
|---|---|---|---|
| `Set()` | O(1) | O(1) | Инициализация указателя `root` в `nullptr` и счётчика `count` в 0. |
| `~Set()` | O(n) | O(n) | Рекурсивный обход всех узлов для освобождения памяти. |
| `insert` | O(log n) | O(n) | Спуск по дереву (в среднем дерево сбалансировано, в худшем — вырождается в список). |
| `contains` | O(log n) | O(n) | Спуск по дереву до нахождения элемента или листа. |
| `remove` | O(log n) | O(n) | Спуск + поиск минимального элемента в правом поддереве (при удалении узла с двумя детьми). |
| `size()` | O(1) | O(1) | Возврат значения поля `count`. |
| `print()` | O(n) | O(n) | Симметричный обход (In-order) всех узлов для вывода. |

### Пояснения к сложности

1. **Средний случай `O(log n)`** — когда дерево сбалансировано (например, элементы добавляются в случайном порядке). Высота дерева ≈ `log₂(n)`, поэтому мы делаем `log₂(n)` шагов вниз.
2. **Худший случай `O(n)`** — когда элементы добавляются по возрастанию (например, `1, 2, 3, 4...`). Тогда дерево вырождается в «связанный список» (каждый узел имеет только правого ребёнка), и поиск занимает `n` шагов.
3. **`O(1)` для `size()`** — мы не обходим дерево, а просто возвращаем готовое число из переменной `count`.
4. **`O(n)` для деструктора и `print()`** — нужно посетить каждый узел ровно один раз.

### Сравнение с STL

| Критерий | `Set<T>` (наша реализация) | `std::set` (STL) |
|---|---|---|
| **Структура** | Бинарное дерево поиска (BST) | Красно-чёрное дерево (сбалансированное) |
| **Средняя сложность** | `O(log n)` | `O(log n)` |
| **Худшая сложность** | `O(n)` (вырожденное дерево) | `O(log n)` (всегда сбалансировано) |
| **Память** | Ручное управление (`new` / `delete`) | Автоматическое (RAII) |

## Контрольные вопросы

**1. Что такое О-нотация (Big O) и зачем она нужна?**

O-нотация — математическая запись, описывающая, как растёт время работы алгоритма при увеличении входных данных. Она нужна для сравнения эффективности алгоритмов независимо от «железа», отбрасывая константы и младшие члены.

**2. Какая сложность у доступа к элементу массива по индексу? Почему?**

O(1) — константная. Адрес элемента вычисляется по формуле `адрес = начало + индекс × размер`, независимо от размера массива.

**3. Какая сложность у бинарного поиска? Почему?**

O(log n). На каждом шаге отбрасывается половина оставшихся элементов, поэтому количество шагов = log₂(n).

**4. Что означает сложность O(n log n)? Приведите пример алгоритма.**

Комбинация линейного и логарифмического роста. Пример — быстрая сортировка (QuickSort), сортировка слиянием (MergeSort).

**5. Что такое амортизированный анализ? Приведите пример.**

Средняя сложность операции за длительное время. Пример: `push_back` в `std::vector` — обычно O(1), но иногда O(n) при реаллокации. Амортизированно — O(1).

**6. Какая сложность у двух вложенных циклов по n итераций каждый?**

O(n²) — квадратичная. `n × n = n²`.

**7. Какая сложность у рекурсивного вычисления чисел Фибоначчи?**

O(2ⁿ) — экспоненциальная. Каждый вызов порождает два новых.

**8. Что такое шаблоны функций? Как их объявить и использовать?**

Шаблоны — обобщённые функции, работающие с разными типами:

```cpp
template <typename T>
T max(T a, T b) { return a > b ? a : b; }
max(5, 10);       // T = int
max(3.14, 2.71);  // T = double
```

**9. Что такое шаблоны классов? Как их объявить и использовать?**

Обобщённые классы для разных типов:

```cpp
template <typename T>
class Stack { T* data; /* ... */ };
Stack<int> s1;
Stack<string> s2;
```

**10. В чём преимущество шаблонов перед перегрузкой функций?**

Меньше кода — одна шаблонная функция вместо множества перегруженных. Работает с любыми типами, включая пользовательские, без их изменения.

**11. Как указать, что шаблонный параметр — тип?**

`template <typename T>` или `template <class T>`.

**12. Можно ли создать шаблон с несколькими параметрами типов?**

Да: `template <typename T1, typename T2>`.

**13. Как провести экспериментальное измерение времени выполнения?**

С помощью `std::chrono`:

```cpp
auto start = high_resolution_clock::now();
// ... операция ...
auto end = high_resolution_clock::now();
auto time = duration_cast<microseconds>(end - start).count();
```

**14. Почему при измерении времени нужно выполнять операцию многократно?**

Одна операция может выполняться за наносекунды — точность измерения низкая, а накладные расходы на замер велики. Многократное повторение сглаживает шум и даёт стабильный результат.

**15. Что важнее: сложность алгоритма или константа?**

Для больших данных важнее сложность (асимптотика). Для малых данных константа может быть решающей. Например, O(n) с большой константой может проигрывать O(n²) при маленьких n.
